Olá, este é um Projeto acadêmico de um sistema de login seguro desenvolvido com Java, Spring Boot, Spring Security, Thymeleaf e MongoDB Atlas. O sistema terá cadastro, login, logout, validação de dados, senhas protegidas por hash e controle de acesso com três perfis de usuário, armazenando usuários e sessões no Atlas. A estrutura será modular, com a interface separada da lógica de negócio, permitindo personalizar o tema. O código será disponibilizado em um repositório público no GitHub pessoal, seguindo Gitflow, e acompanhado de documentação em PDF conforme as normas ABNT. O projeto nmo momento está em desenvolvimento.
